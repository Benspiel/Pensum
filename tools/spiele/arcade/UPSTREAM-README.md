<details>
<summary><b>Scoring and power-ups</b></summary>

<br />

| Game | How you score |
| --- | --- |
| **Breakout** | Each brick is worth `10 × its hit points × combo`. The combo counts bricks broken since the ball last touched the paddle (max ×8). Clearing a level adds `250 × level`. |
| **Snake** | Food is worth 10, multiplied by 1 more for every 10 eaten. Every 5th food spawns a bonus star worth 50 plus 10 for each second left on its timer. |
| **Stack** | 1, 2, 3 or 4 lines score 100, 300, 500 or 800 × level. Back-to-back quads score ×1.5, combos add `50 × combo × level`, and drops add 1 point per row (2 for hard drops). Level up every 10 lines. |
| **Astro Blaster** | Large rocks 20, medium 50, small 100, saucer 500. Extra life every 10,000 points. |
| **Runner** | 1 point per metre plus 25 per coin. |
| **Star Siege** | Aliens are worth 10, 20 or 30 by row, the mothership 50 to 300, and clearing a wave adds `100 × wave`. |
| **Neon Hop** | 10 for each new row reached, 50 per dock plus 10 for each second left, 200 for the bonus orb, and 1,000 for filling all five docks. |
| **Neon Pong** | Against the CPU: 100 per point you win, plus 500 and 100 for each point of margin if you take the match. |
| **Neon Maze** | Dots 10, power cells 50, chasers 200, 400, 800 and 1,600 in one scare, and bonus chips from 100 up to 2,000 by level. Extra life at 10,000. |
| **Neon Pinball** | Bumpers 100, slingshots 50, drop targets 200 (1,500 for the whole bank), standups 300, lanes 250 (1,000 for all three). Everything is multiplied by the current multiplier. |
| **Neon Lander** | Each landing pays a base that grows with the stage, more for a narrow pad, 2 per unit of fuel left, and 50 for a soft touchdown. |
| **Neon Mines** | A cleared board scores its difficulty's base points plus a bonus for every second under par. A lost board scores the safe cells uncovered. |
| **Neon Golf** | `(11 - strokes) × 100` per hole, so fewer strokes always score higher. Water costs a penalty stroke and each hole is capped at 10. |
| **Neon Crates** | Up to 1,000 per level, scaled by par over your moves. |
| **Neon Match** | Each match scores by its size, multiplied by the cascade chain. Line gems clear a row or column, bombs clear the area around them. |
| **Neon Bubbles** | Popped bubbles score, dropped ones score a growing bonus each, a streak of popping shots multiplies up to x4, and clearing the field pays a big bonus. |
| **Neon Tanks** | No score: win two rounds to take the match. Wins against the CPU build a saved streak. |

**Breakout power-ups:** green **W** widens the paddle for 12 seconds, purple **M** splits the ball into three, yellow **S** slows the ball to 70% for 8 seconds, and the rare pink **+** is an extra life.

## Features

<p align="center">
  <img src=".github/assets/hub.png" alt="The GH Arcade hub with game cabinets, tag filters, and Trophies and Settings buttons" width="100%" />
  <br />
  <sub>The hub: every game gets a cabinet card, filterable by tag, with your best score on it once you've played.</sub>
</p>

| Feature | Details |
| --- | --- |
| **Plays anywhere** | A static site on GitHub Pages. Loads straight in the browser on desktop, tablet or phone. |
| **Installable, works offline** | Install GH Arcade as an app from the hub. After one visit, every game plays with no connection. |
| **Keyboard, touch or gamepad** | Every game supports all three. Plug in a controller and it just works, including pause on <kbd>Start</kbd>. If a controller disconnects mid-run, the game pauses. |
| **Two-player** | Neon Snake and Neon Pong have versus modes and Star Siege has co-op, on one keyboard or two gamepads. Neon Tanks is a hot-seat duel, taking turns on one device. |
| **Daily challenges** | Neon Stack, Neon Hop, Neon Runner, Neon Snake, Astro Blaster, Star Siege, Neon Lander, Neon Mines and Neon Bubbles have a Daily mode: the same game for everyone on a given UTC date, with its own best score and a streak. (In Snake the food and bonus stars follow a shared sequence, so runs match for as long as players steer the same way; in Astro Blaster and Star Siege the rocks, the saucer, the alien fire and the mothership do. Lander shares its terrain, pads and wind, Mines its board, and Bubbles its starting field, its new rows and the bubbles it deals.) The hub counts down to the next challenge (midnight UTC), a card whose daily is still waiting opens the game on DAILY, and a shared daily result links to it (`games/<slug>/?mode=daily`). |
| **Pause menu and game over** | Every game pauses into a menu: resume, restart, settings (volume, sound, motion, colors and gamepad rumble), main menu or back to the arcade. Game over shows the trophies you just earned, with Play again, Menu and Arcade options. |
| **Page controls** | On-screen pause and fullscreen buttons, a loading indicator, and a hint to rotate your phone for games that play best in landscape. The screen stays on during a run, even when you play with a gamepad, and may sleep again once you pause or the run ends. |
| **Couch-friendly hub** | Browse the cabinets with the arrow keys or a gamepad: <kbd>A</kbd> opens a game, <kbd>LB</kbd> <kbd>RB</kbd> switch filters, <kbd>Y</kbd> shows trophies and <kbd>Start</kbd> opens settings. Inside a panel, up and down move between its controls (and scroll it), left and right change a slider, <kbd>A</kbd> presses a button or ticks a box, and <kbd>B</kbd> closes it. |
| **Trophies and stats** | 71 trophies across the arcade, with plays and best scores per game in the Trophies panel. Saved on your device, no sign-up. |
| **Settings and accessibility** | Volume, reduced motion (no shake or flashes), a colorblind-friendly palette, rebindable keys and gamepad buttons, gamepad rumble on impacts (can be turned off), and touch options: button size, a left-handed layout and vibration. |
| **Zero-asset audio** | Sound effects are synthesized live with the Web Audio API, so there are no audio files to download. |
| **Fast loads** | Each game is its own page and bundle. Phaser is split into one shared file that your browser caches across games. |
| **One command per game** | `npm run new-game` scaffolds a working game and adds it to the hub. No build config to edit. |

<a id="quick-start"></a>

## Quick start

Requires **Node 22.13 or newer** (CI checks Node 22.13 and 24).

```bash
git clone https://github.com/TMHSDigital/GH-Arcade.git
cd GH-Arcade
npm install
npm run dev
```

Then open **http://localhost:5173/GH-Arcade/**.

| Script | What it does |
| --- | --- |
| `npm run dev` | Dev server with hot reload |
| `npm run build` | Type-check, then production build into `dist/` (including the service worker) |
| `npm run preview` | Serve the production build locally, to test offline mode and installing |
| `npm run typecheck` | TypeScript check only |
| `npm run lint` | Lint with ESLint |
| `npm test` | Run the unit tests (Vitest) |
| `npm run new-game <slug> ["Title"]` | Scaffold a new game |

> [!TIP]
> In dev mode the running Phaser game is exposed as `window.game`, so you can inspect scenes from the browser console, for example `game.scene.getScene('Game')`. This is removed from production builds.

## Make your own game

Adding a game takes three steps, and no build config to edit.

### 1. Scaffold it

```bash
npm run new-game space-dodge "Space Dodge"
```

This copies `games/_template/` to `games/space-dodge/`. The template is a small, playable Phaser game in the same shape as the shipped games: `config.ts`, a menu scene, a game scene and the shared game-over screen, with keyboard, touch and gamepad controls, pause, high scores and play counts already wired up. The command also adds a card for it to the hub and prints what is left to do by hand (card text, thumbnail, trophies).

### 2. Describe it

Edit the new entry in [`games/registry.json`](games/registry.json). This is what the hub card shows. The scaffolder fills it with a placeholder description and a `new` tag, which appear on the live hub until you replace them.

```jsonc
{
  "slug": "space-dodge",              // folder name and URL: /games/space-dodge/
  "title": "Space Dodge",             // card title
  "description": "Weave through…",    // card blurb
  "tags": ["arcade", "shooter"],      // hub filter chips
  "accent": "#a45bff",                // card glow color
  "controls": "Arrows / touch",       // controls hint on the card
  "thumbnail": "thumbs/space-dodge.jpg" // optional 16:9 screenshot in public/; without it the card shows a big letter
}
```

### 3. Build it

Run `npm run dev`, open `/GH-Arcade/games/space-dodge/` and start editing `scenes/GameScene.ts`. Vite picks up every `games/*/index.html` automatically, and the service worker precaches it for offline play. Push to `main` and it's live.

### The shared toolkit

Games import ready-made building blocks from [`shared/`](shared), so a new game gets menus, controls, pause and high scores for free:

```ts
import { ArcadeControls } from '../../shared/controls';
import { PauseController } from '../../shared/pause';
import { startArcadeGame } from '../../shared/phaser-config';
import { ArcadeGameOverScene } from '../../shared/scenes';

class GameScene extends Phaser.Scene {
  create() {
    this.controls = new ArcadeControls(this);                // keyboard + gamepad + touch in one API
    this.pause = new PauseController(this, this.controls);   // P / Esc / Start, mute, auto-pause
  }
  update() {
    if (this.pause.isPaused) return;
    this.player.x += this.controls.axisX * 5;                // analog stick or arrow keys
    if (this.controls.justPressed('action')) this.jump();    // Space, Enter or gamepad A
  }
}

startArcadeGame({ scenes: [MenuScene, GameScene, ArcadeGameOverScene] });
```

**Scene keys.** The shared modules find scenes by key, exported as `SCENE` from [`shared/scenes.ts`](shared/scenes.ts): the menu scene is `'Menu'`, the gameplay scene is `'Game'` and the shared game-over scene is `'GameOver'`. The pause menu's MAIN MENU and RESTART, the menu's start prompt and the game-over options all navigate by these keys, so keep them when you rename or add scenes. End a run with `endRun(this, { gameId, score })` from the same module; the game-over screen it starts saves the best score and records the play.

| Module | What it provides |
| --- | --- |
| [`controls.ts`](shared/controls.ts) | `ArcadeControls`: keyboard, gamepad and on-screen touch input behind `isDown()`, `justPressed()` and `axisX`/`axisY`, with extra per-game bindings, and `rumble()` for that player's gamepad. |
| [`pause.ts`](shared/pause.ts) | `PauseController`: pause and mute keys, a pause menu (resume, restart, settings, main menu, arcade), and auto-pause when the tab loses focus or a gamepad disconnects. |
| [`menu.ts`](shared/menu.ts) | `OptionMenu`: a row or column of choices that works with keys, gamepad, mouse and touch. |
| [`modes.ts`](shared/modes.ts) | Links to a menu mode: `?mode=<label>` in a game's address opens its menu on that mode (`?mode=daily`, `?mode=2-players`). `buildMenu()` reads it, so games with `modes` need nothing extra. |
| [`chrome.ts`](shared/chrome.ts) | The page around the canvas: pause and fullscreen buttons, the loading indicator and the rotate hint. It also keeps the screen on during a run ([`wake-lock.ts`](shared/wake-lock.ts)), which any game with a `PauseController` gets for free. |
| [`touch.ts`](shared/touch.ts) | `onSwipe()` gestures, plus `VirtualStick` and `VirtualButton`. Games check `isTouchDevice()` before creating the on-screen controls. |
| [`scenes.ts`](shared/scenes.ts) | `buildMenu()` title screens and the shared `ArcadeGameOverScene` with high-score checks and a share option ([`share.ts`](shared/share.ts)). |
| [`ui.ts`](shared/ui.ts) | Neon text, the HUD text style, banners, score popups, particle bursts and the shared color palette. `impact()` shakes the screen and rumbles the gamepads of the players it happened to; use it instead of calling the camera shake directly. |
| [`phaser-config.ts`](shared/phaser-config.ts) | `startArcadeGame()`: fit-to-screen Phaser setup with gamepads enabled, once the pixel font has loaded. |
| [`storage.ts`](shared/storage.ts) | `loadJSON()` and `saveJSON()`, backed by `localStorage` that never throws. If the browser blocks saved data, every page says so once (`storage-notice.ts`). |
| [`sfx.ts`](shared/sfx.ts) | `tone()` and `noise()`: retro sound effects synthesized with Web Audio. |
| [`achievements.ts`](shared/achievements.ts) | Trophies, stats and best scores. Each game lists its trophies in its own `trophies.ts` and gets type-checked `unlock()`, `reach()` and `addCounter()` helpers from `trophiesFor()`; `getHighScore()` returns a game's best and `getTopScores()` its five highest. Unlocks pop up as a [toast](shared/toast.ts). A game that saves bests of its own lists their keys as `BEST_KEYS` in `trophies.ts`, so resetting best scores clears them too. |
| [`settings.ts`](shared/settings.ts) | Player settings (volume, reduced motion, palette, key and gamepad bindings, rumble) that every game reads on start. |
| [`backup.ts`](shared/backup.ts) | Export, import (replace or merge) and reset of everything saved on the device, used by the hub's settings dialog. |
| [`rng.ts`](shared/rng.ts) | `createRng(seed)`: repeatable random numbers with `between`, `pick` and `shuffle`, plus what a daily challenge needs: `dailySeed()`, `dailyRng()`, `DAILY_MODES` for the menu (or `DAILY_MODE_LABEL` to add DAILY to a menu that already has modes), per-day best scores with history and a streak, `dailyRunFrom()` and `diceFor()` to seed a scene's random choices, and `dailyResult()` for the game-over line. Give the game the `daily` tag in `registry.json` so the hub shows today's result. |
| [`frame.ts`](shared/frame.ts) | `frameSeconds(deltaMs)`: a frame's length in seconds, capped so a stalled tab never makes the game jump. Use it for `dt` in every `update()`. |
| [`pwa.ts`](shared/pwa.ts) | Registers the service worker that makes every page work offline, and announces when the arcade is ready offline or has updated. |

> [!NOTE]
> Phaser is the default engine, but it's optional. A game is just an `index.html` with a script, so plain Canvas, Three.js or anything else Vite can bundle will work.

## How it works

Every push to `main` publishes the site automatically:

1. **Push** to `main` triggers the [deploy workflow](.github/workflows/deploy.yml).
2. **GitHub Actions** installs dependencies with `npm ci`, then runs `npm run lint`, `npm test` and `npm run build`.
3. **The build** type-checks the code, bundles the hub plus every `games/*/index.html` with Vite, and generates a service worker that precaches all of it.
4. **GitHub Pages** serves `dist/` at [tmhsdigital.github.io/GH-Arcade](https://tmhsdigital.github.io/GH-Arcade/). After the first visit, the service worker serves every page and game offline and picks up updates automatically.

<details>
<summary><b>Design decisions</b></summary>

<br />

- **Vite multi-page build, not a single-page app.** Each game is an independent page, so one game can't break another, and each one loads only its own code.
- **Shared Phaser chunk.** Phaser is about 340 KB gzipped. It's split into its own file so it downloads once and is cached for every game.
- **Procedural art and audio.** Games draw their graphics in code and synthesize their sounds, so each game adds only a few KB on top of Phaser.
- **One input layer.** Games ask `ArcadeControls` about actions ("left", "action") instead of keys, so keyboard, gamepad and touch all work without per-game plumbing.
- **Rules separate from rendering where it pays off.** Neon Stack's rules are pure functions in `logic.ts`, which keeps rotation, wall kicks and line clears easy to test. Snake, Maze, Runner, Hop and Pong keep theirs in Phaser-free modules too (`logic.ts`, `chase.ts`, `rules.ts`), and so does every newer game: Lander's physics, the Mines board, Golf's ball and holes, the Crates rules, the Match board, the Bubbles hex grid and the Tanks terrain, shells and CPU are all tested without Phaser.
- **Offline first.** Everything is precached at build time, and all pages share one font stylesheet so a single visit caches it for every game.

</details>
